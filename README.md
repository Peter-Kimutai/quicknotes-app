# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organize, search and delete notes. Notes can be categorized as Personal, Work or Study, and are automatically saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes with a text description
- Categorize notes as Personal, Work or Study
- Display the date and time each note was created
- Delete individual notes
- Search notes by text
- Search is case-insensitive
- Validate notes before adding them
- Prevent empty notes
- Limit notes to 200 characters
- Display the total number of notes
- Save notes using localStorage
- Load saved notes when the page opens
- Responsive layout for smaller screens
- Category-specific visual styles
